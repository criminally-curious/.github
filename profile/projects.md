# What's in the machine?

## Butch

Butch is our Discord bot and a practical place to learn bot architecture. Her working pieces include command handling, member preferences, reply delivery, and state that survives a restart.

The source is a private collaborator project. Existing collaborators have a contributor guide, a first issue, and a Discord workbench. Source access and production permissions are handled for each contributor. You can participate under an alias; no real name or work history is required.

The learning path starts with a small feature someone can own, tests they can understand, and review before deployment. Optional teaching inside Discord is part of the direction being explored. Project documentation records what is implemented and what remains a proposal.

Interested in helping? [Ask a question](https://github.com/criminally-curious/.github/issues/new/choose) with what you want to work on. Keep private project details in its existing collaborator spaces.

## IconForge

[IconForge](https://github.com/villagealchemist/iconforge) is villageAlchemist's existing macOS icon project. Its source, releases, installation instructions, and contribution history remain in that repository.

Start with its README and choose a change small enough to explain. Useful feedback and clear bug reports are contributions too.

## Series of Tubes

Series of Tubes is architecture work around tools, services, contracts, and explicit permissions.

AAPI is the runtime boundary. MCCP describes the semantic contract. Port Authority evaluates whether an operation is allowed, needs approval, or is denied. Different prototypes implement different parts of that path; their documentation keeps evaluation, execution, and unfinished work distinct.

The aim is to make the tubes understandable enough that someone else can build with them. Questions about the architecture are welcome. Start with the thing you are trying to do and the part that does not make sense yet.
