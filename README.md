GitHub displays the public profile from the profile directory. Its relative image and documentation links remain usable when the organization handle changes.

The actual organization avatar is uploaded through GitHub's profile settings. The prepared upload file is below.

```text
profile/assets/avatar-smiley.png
```

The current avatar is the picture supplied by villageAlchemist, copied without changing its pixels. The matching banner was generated from that visual reference. The direction combines a holographic pirate smiley, pink and purple collage, concentric rings, and acid-yellow type.

The earlier chrome question-mark artwork remains in the repository as a previous direction. The public profile uses the smiley banner.

This repository contains profile content and documentation. Hosted Actions are disabled. It has no runtime credentials, model service, or bot deployment.
