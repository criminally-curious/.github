# Criminally Curious

This repository holds the organization's public profile, original artwork, and shared contribution guidance.

- [Public profile](profile/README.md)
- [Project notes](profile/projects.md)
- [Contribution guide](CONTRIBUTING.md)
- [Artwork and source prompts](brand/README.md)

GitHub displays the public profile from the profile directory. Its relative image and documentation links remain usable when the organization handle changes.

The actual organization avatar is uploaded through GitHub's profile settings. The prepared upload file is below.

```text
profile/assets/avatar.png
```

The banner and avatar are original artwork generated for this organization. The palette and visual direction draw on 1990s cyber-rave posters, chrome hardware, and CRT texture.

This repository contains profile content and documentation. Hosted Actions are disabled. It has no runtime credentials, model service, or bot deployment.
